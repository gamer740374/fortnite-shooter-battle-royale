# Battle Royale 3D Shooter Prototype

Ein kleines browserbasiertes 3D-Battle-Royale-Shooter-Projekt in HTML + JavaScript mit Three.js.

## Spielidee
- 3D-Spielwelt mit Wiese, Bäumen und Kampfzone
- WASD-Bewegung + Maussteuerung
- Schießen mit Linksklick
- Gegner spawnen und laufen auf den Spieler zu
- Safe Zone zieht sich langsam zusammen
- Power-Ups für Gesundheit und Munition
- Sieg oder Niederlage je nach Überleben

## Starten
1. In das Projektverzeichnis wechseln
2. Einen lokalen Webserver starten:

```bash
python3 -m http.server 8000
```

3. Im Browser öffnen:

```text
http://localhost:8000
```

## Steuerung
- W/A/S/D: laufen
- Maus: Blickrichtung
- Linksklick: schießen
- Space: schießen
- Rechte Maustaste nicht genutzt

## Hinweis
Das ist ein funktioneller Prototyp, kein komplettes Fortnite-Klon. Er zeigt die Kernmechanik eines 3D-Battle-Royale-Shooters in einfacher Form.
